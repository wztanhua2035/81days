# 《八十一天》v2.10

单人荒岛卡牌冒险网页游戏，可直接部署到 Zeabur。

## v2.10 本次调整

- 探索结束后的“探索结果”显示框在手机端扩大约 50%，中、大字号获得更大的结果阅读区域，同时略微压缩结果页的场景图高度，让大字号下更少依赖内部滚动。
- 人物互动模板由 92 组增加到 102 组：清理 5 组与深层剧情主题重复较高的旧模板，并加入 15 组全新互动，因此净增加 10 组。新增内容涵盖求救信号练习、萤火虫、鞋底修补、海鸟观察、小游戏、气味记忆、绳结练习、急救互检、方向校正、晒衣、物资底线、林中回声、获救后的小愿望、工具维护、窝棚生活感等。
- 调整 8 件使用率较低或效果偏弱的非消耗物品：防水航线图、折叠望远镜、荧光标记带、轻量浮力背心、加厚工作手套、防风防水火柴盒、救援口哨、折叠信号镜。它们现在拥有更明确、更容易触发的探索、攀爬、涉水、生火、资源采集或求救加成。
- 救援口哨与折叠信号镜的求救加成已经接入实际求救事件结算，不只是文字说明。
- 普通难度回归模拟仍保持约 53% 平均通关率，NPC 前30天和前60天死亡率继续低于既定上限。
- 本次不改变核心存档结构，可继续使用 v2.9 / v2.8 的当前存档。

## v2.9 本次调整

- 当前地点场景里的可滚动描述框面积扩大约 50%；中、大字号下进一步增加可用高度，减少为了看两三行文字频繁上下滑动。
- 新的一天进入“留在当地 / 前往其他地点”选择前，玩家已经可以打开背包并使用可消耗道具；打开地图尚未确定目的地时也仍可使用。
- 全局人物关系的正负变化幅度统一提高约 25%，使人物选择反馈更鲜明；关系数值仍限制在 -100～100，情侣/生死之交/敌对等阈值保持不变。
- 交易、赠送、剧情结果等涉及关系数值的提示会显示实际生效后的关系变化值。
- 本次不改变存档结构，继续兼容 v2.7 的当前存档。

## 本地运行

```bash
npm start
```

默认地址：

```text
http://localhost:3000
```

管理后台：

```text
http://localhost:3000/admin
```

默认管理密码：

```text
818181
```

首次部署后请尽快修改管理密码。

## Zeabur 部署

1. 将项目上传 GitHub。
2. 在 Zeabur 新建 Project。
3. Deploy New Service → GitHub → 选择仓库。
4. 启动命令使用 `npm start`。
5. 绑定域名即可。

游戏会自动读取 `process.env.PORT`。

### 持久化提醒

排行榜和后台参数建议继续使用 Zeabur Volume，例如：

```text
/data
```

并设置：

```text
ADMIN_DATA_DIR=/data
```

后台上传的背景音乐按本次要求直接写入：

```text
public/assets/music
```

Zeabur 重新构建容器时，运行时上传的文件可能会丢失。若希望后台上传的音乐长期保留，请额外把 Volume 挂载到项目的 `public/assets/music` 目录，或在确认曲目后把音乐文件提交回 GitHub 仓库。

## v2.9 界面反馈优化

- 动物互动、交易、赠送、抢夺等操作进入“行动结果”阶段后，场景图中央会显示刚刚互动的角色或动物头像与名称。

- “结束互动”按钮改为独立的深蓝灰配色和亮色文字，与交易、赠送、抢夺按钮明显区分。
