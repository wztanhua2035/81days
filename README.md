# 《八十一天 DAY 81》v1.9

单人卡牌 / 荒岛生存 / 人物关系 / 智能NPC / 营地与个人窝棚网页游戏，可直接部署到 Zeabur。

## v1.9 核心变化

- 手机主游戏页改成“单屏 HUD + 中央游戏区 + 底部快捷栏”。背包、角色状态、人物关系、公共营地、个人窝棚和日志改为弹层打开，减少整页上下滚动。
- 其他5名角色增加 AI 智能等级，并根据健康、生命、食物、公共营地储备、自己的窝棚、与主角关系等因素选择每日目的地，不再只是随机移动。
- NPC 会主动前往公共营地，并在缺水或缺食物时取用营地净水和食物储备。
- 每名角色都能拥有一座个人窝棚。玩家可在当天确定的任意地点搭建，窝棚最高3级：`简易窝棚 → 遮风小屋 → 坚固木屋`。
- 3级窝棚各有不同的日式动漫风内部场景图。只有回到自己的窝棚所在地时，玩家才能进入内部、升级和制作设施。
- 窝棚最多安装4件设施，可从舒适吊床、净水装置、干燥架、简易炉灶、医疗角中选择。
- NPC 也会根据自己的 AI 智能、日期和公共材料储备搭建、升级自己的窝棚并制作设施。
- 六位角色特殊技能大幅加强：林岚医疗恢复、周野减伤与战斗、陈默维修与建造、苏晴探索、高远食品利用、许棠检定重试均明显增强。
- 夜间同地点角色按关系亲密度有40%—80%概率触发互动。关系越亲密，互动越容易发生，出现正向关系/状态效果的概率也越高。
- 玩家真正完成12个地点各至少一次“探索”后，会随机获得一项全岛探索奖励。
- 其他角色死亡时会弹出醒目的死亡警告，显示人物头像、死亡日期和原因。
- 保留12地点动漫场景图、60组地点探索事件、60组人物互动、情侣专属互动、连续剧情、大危机、公共营地、三档难度、排行榜、管理后台和手机音效解锁。

## 个人窝棚

### Lv.1 简易窝棚

基础临时住所，可降低部分夜间日常消耗。

### Lv.2 遮风小屋

明显提升防风雨和野兽能力，并提高休息质量。

### Lv.3 坚固木屋

最高等级住所，夜间更加安全舒适。

窝棚材料使用公共材料储备中的木材、藤条和零件。陈默拥有工程大师能力，搭建和升级时会自动节省部分材料。

## 本地启动

```bash
npm start
```

打开：`http://localhost:3000`

管理后台：`http://localhost:3000/admin`

默认管理密码：`818181`（部署后请立即修改）。

## Zeabur

1. 将本目录完整上传到 GitHub。
2. Zeabur 新建 Project → Deploy New Service → GitHub。
3. 选择仓库后直接部署；启动命令为 `npm start`。
4. 建议挂载持久化 Volume 到 `/data`，并设置环境变量：

```text
ADMIN_DATA_DIR=/data
```

这样管理后台设置与排行榜会在重新部署后继续保留。
