# 八十一天 DAY 81 · v1.5

单人卡牌荒岛生存网页小游戏。无需数据库、无需大模型 API，可直接部署到 Zeabur。

## v1.5 核心升级

- **背包扩展为 8 格**。每位角色的初始道具改为角色专属永久物品，占用一个背包格，但永远不可交易、不可被夺取、不可失窃、不可丢弃，也不会因普通损坏事件消失。
- 六件专属初始道具分别变为被动能力道具，避免“永久急救包/罐头可无限消耗”的不合理情况。
- 每天清晨或移动到新地点后，先显示一段该地点当天状况描述，再由玩家选择：**探索、与同地点角色互动、移动到其他地点、留在原地休整**。
- 重做人物相遇：不再把“遇到人”直接等同于战斗/交易。人物会结合职业、关系和当前地点说简短对白，并给出不同回应选项；选择可改变人物关系、状态或获得线索。
- **敌对人物同地点时，每天首次进入该地点有 20% 概率直接爆发战斗**；其余时候仍可保持距离或出现冷淡对话。
- **信任及以上关系才可以交易**。玩家只能选择自己拿出的普通道具，对方会根据自己的需求自动决定拿什么交换；双方任意一方没有可交易道具时不能交易。
- 地点随机事件由 **24 个增加到 36 个，正好 +50%**，12 个地点各有 3 个三选一事件，并对部分不合理旧事件进行了改写。
- 普通可获得道具由 **31 种增加到 41 种，约 +32%**，另外保留 6 件角色专属永久初始道具。
- 调整部分道具效果，例如 **苹果改为生命 +1**；同时增加野香蕉、密封肉干、能量棒、弹性绷带、口服补液盐、耐磨手套、驱虫喷雾、防水火柴、轻便吊床、便携滤水器等。

## 六件角色专属初始道具

- 林岚：**随身急救包** — 医疗类检定 +15%。
- 周野：**消防救援绳** — 攀爬、救援类检定 +25%。
- 陈默：**工程工具包** — 机械、维修类检定 +20%。
- 苏晴：**户外指南针** — 迷路类事件获得稳定优势。
- 高远：**厨师折叠刀** — 食物处理、采集类检定提高。
- 许棠：**防水教学笔记本** — 探索、记录类检定提高。

以上道具都是人物身份的一部分，永久持有，不进入普通交易、掠夺、失窃和丢弃逻辑。

## 每日主要流程

```text
新的一天
↓
显示 DAY 转场 / 低生命警告 / 大危机预告
↓
显示当前地点当天状况
↓
若同地点有敌对人物，20%概率爆发冲突
↓
选择今天的主要行动
├─ 探索当前地点 → 地点专属三选一事件
├─ 与同地点角色互动 → 对话 / 帮忙 / 询问 / 信任交易
├─ 移动到其他地点 → 显示新地点状况 → 再选择行动
└─ 原地休整 → 降低当天自然消耗
↓
其他 NPC 自主行动与移动
↓
大危机或夜间特别事件
↓
每日状态结算
↓
下一天
```

## 人物互动与关系

人物关系范围 -100～100，显示为：

- 敌对
- 冷淡
- 普通
- 信任
- 生死之交

同地点相遇时，会根据对方身份、关系等级和地点生成短对白。例如护士更容易关注伤势，工程师会谈零件和结构，摄影师更关注路线和环境，厨师更关注食物，教师更偏向计划和沟通。

玩家可根据场景选择帮忙、询问信息、一起处理问题、谨慎回应或结束交谈。互动结果可能：

- 改善或恶化关系；
- 获得状态恢复或检定优势；
- 获得普通物资；
- 推进人物或连续剧情；
- 在敌对关系下触发冲突。

### 交易规则

- 双方关系必须达到 **信任** 或更高。
- 双方都必须至少拥有 1 件普通可交易道具。
- 玩家只选择自己拿出的 1 件物品。
- NPC 根据健康、生命、背包和道具价值自行选择交换物。
- 不能指定 NPC 必须拿出哪件物品。
- 角色专属初始道具永远不会进入交易。

### 战斗和夺取

战斗沿用力量 + 敏捷 + 武器修正的算法。胜者只能从失败者的**普通可夺取道具**中随机取得一件；专属初始道具永远不会成为战利品。

## 道具系统

默认背包容量为 **8 格**。

- 1 格通常由专属初始道具长期占用。
- 其余格子可以保存普通食物、医疗用品、工具和求救物资。
- 背包满时必须丢弃一件普通道具或放弃新道具。
- 专属初始道具不会出现在“丢弃”列表。

普通道具共 41 种，包含食物、医疗、工具和特殊求救物资。

### 部分调整后的道具

- 苹果：生命 +1。
- 椰子：健康 +1，少量概率额外恢复。
- 罐头：健康 +2。
- 压缩饼干：健康 +1，且当晚不因日常消耗下降健康。
- 能量棒：健康 +1，并提高下一次检定。
- 急救包 / 弹性绷带：生命 +1。
- 口服补液盐：健康 +1，并降低当晚自然消耗。
- 轻便吊床：休整时获得更好效果。
- 便携滤水器：提高饮水、淡水事件成功率。
- 驱虫喷雾：降低虫群、沼泽类不良影响。



建议首次部署后立即修改。后台可以调整六位角色姓名、正常难度基础参数、夜间概率、检定修正、健康消耗、回血概率、背包容量和管理密码。

当前默认背包容量：**8**。

## Zeabur 数据持久化

排行榜和管理后台设置保存在服务器数据目录。正式使用建议在 Zeabur 挂载 Volume，例如 `/data`，并设置：

```text
ADMIN_DATA_DIR=/data
```

这样管理密码、后台设置和排行榜不会因为重新部署而丢失。玩家个人游戏进度保存在各自浏览器 localStorage。

## Zeabur 部署

1. 解压 ZIP。
2. 将 `day81` 文件夹内全部文件上传到 GitHub。
3. Zeabur → New Project → Deploy New Service → GitHub。
4. 选择仓库，启动命令使用 `npm start`。
5. `server.js` 自动读取 `process.env.PORT` 并监听 `0.0.0.0`。
6. 推荐挂载 `/data` Volume，并设置 `ADMIN_DATA_DIR=/data`。
7. 添加域名即可运行。

项目同时包含 `Dockerfile` 作为备用部署方式。
