# 八十一天 DAY 81 · v1.4

单人卡牌荒岛生存网页小游戏。无需数据库、无需大模型 API，可直接部署到 Zeabur。

## v1.4 核心升级

- 六位可选角色加入统一日式动漫风头像，角色选择、状态栏、人物相遇、关系页和结局页都会显示头像。
- 首页加入海岛主题视觉、角色群像，事件卡、危机提示和人物遭遇界面进一步强化表现。
- 加入 **连续剧情事件链**：当前提供多条 3 段式剧情，玩家前一次的选择会影响后续关系、资源和剧情收益；下一段需要等待若干天并前往指定地点继续。
- 加入 **人物关系系统**：关系分为敌对 / 冷淡 / 普通 / 信任 / 生死之交。交易、战斗、剧情选择、争吵、偷窃和互助都会改变关系；高关系同伴在玩家状态较差时有机会主动帮助。
- 加入 **公共营地建设**：林中空地可以建设遮雨棚、集水器、捕鱼陷阱、求救台。探索会获得木材、藤条、零件；设施建成后提供长期效果。
- 加入 **提前预告的大危机**：热带风暴、高温干旱、野兽迁徙、异常大潮会在 2—3 天前预警，玩家可以提前选择地点、准备道具或建设营地应对。大危机当晚替代普通夜间事件，避免双重惩罚。
- 正常难度仍保持 **70% 夜间特别事件基础概率**，但整体生存压力略微降低：正常难度属性检定、躲避、健康消耗和回血机会都得到小幅友好调整，并提供 1 份额外开局食物。
- 修正手机音效：使用 `touchstart / pointerdown / click` 主动解锁 Web Audio，兼容 iOS Safari、Android Chrome 和微信内置浏览器常见的“电脑有声音、手机无声音”问题。

## 已有主要玩法

- 12 个海岛地点，未探索地点显示为“未知”。
- 6 名幸存者开局随机分布在海岛各处。
- 玩家每天选择一个地点探索，当晚留在该地点；NPC 每天也会自行移动探索。
- 每天清晨，同一地点的幸存者相遇，可躲避、交易或战斗；多人同地点时可选择交互对象。
- 地点专属三选一事件、动态生命/健康变化、逐字事件显示、道具名称高亮、新日转场和低生命警告。
- 夜间事件默认按难度触发；具有地点范围的夜间事件只影响该地点角色。
- 容易 / 正常 / 困难三档难度。
- 服务器排行榜：游戏结束输入 6—8 字符账号，按幸存天数优先、得分次之排序，只保留前 100 名；同账号仅保留更好成绩。
- 密码管理后台：可改角色姓名、正常难度基础参数和管理密码。

## 营地建设

公共营地固定在 **林中空地**。玩家可以随时查看营地，但只有身处林中空地时才能建造或领取储备。

- **遮雨棚**：降低暴雨、寒夜和热带风暴风险。
- **集水器**：每 3 天产生 1 份净水；在营地领取后健康 +1，并减少营地内自然健康消耗。
- **捕鱼陷阱**：每 4 天产生 1 份食物。
- **求救台**：建成时提高求救努力，对最终评分和后期求救路线有帮助。

## 人物关系

人物之间有隐藏数值 -100～100，界面显示为：

- 敌对
- 冷淡
- 普通
- 信任
- 生死之交

主动战斗会快速进入敌对；交易和互助会改善关系。关系较好的同伴可能在同地点清晨主动分享食物或帮助玩家恢复状态。

## 大危机

每局会预先生成数次重大危机日期，并在危机前 2—3 天显示预警。当前包括：

- 热带风暴
- 高温干旱
- 野兽迁徙
- 异常大潮

合适地点、道具和营地设施都可以显著降低危机伤害。

## 手机音效说明

移动浏览器普遍禁止网页在没有用户手势时自动创建/播放声音。v1.4 在首次触摸、点击或按下屏幕时会主动解锁 Web Audio。

如果手机仍没有声音：

1. 点击游戏右上角 `🔇 / 🔊` 一次。
2. 检查手机媒体音量，不是铃声音量。
3. iPhone 请确认没有对网页媒体进行静音限制。
4. 微信内置浏览器如果系统版本较旧，可尝试在 Safari / Chrome 打开同一链接。


```text

```


后台可调整：

- 六位角色姓名
- 正常难度夜间事件基础概率（默认 70%）
- 属性检定基础修正
- 基础躲避成功率
- 健康自然下降概率
- 连续健康良好后的生命恢复概率
- 背包容量
- 开局额外食物
- 管理密码

## Zeabur 数据持久化

管理设置和排行榜保存在服务器数据目录。正式公开使用时建议在 Zeabur 挂载 Volume，例如 `/data`，并设置：

```text
ADMIN_DATA_DIR=/data
```

这样管理密码、后台设置和排行榜不会因为重新部署而丢失。玩家个人游戏进度仍保存在各自浏览器 `localStorage`。



## Zeabur 部署

1. 解压 ZIP。
2. 将 `day81` 文件夹内全部文件上传至 GitHub 仓库。
3. Zeabur → New Project → Deploy New Service → GitHub。
4. 选择仓库，启动命令使用 `npm start`。
5. `server.js` 会读取 `process.env.PORT` 并监听 `0.0.0.0`。
6. 推荐挂载 `/data` Volume，并设置 `ADMIN_DATA_DIR=/data`。
7. 添加域名即可运行。

项目同时提供 `Dockerfile` 作为备用部署方式。
