# 《八十一天 DAY 81》v1.7

单人卡牌 / 荒岛生存 / 人物关系 / 连续剧情 / 营地建设网页游戏，可直接部署到 Zeabur。

## v1.7 核心变化

- 健康值已为3时继续获得健康：若生命未满，则生命+1且健康变为1；若生命已满，则健康保持3。
- 每天在开始探索、休整或人物互动前可以移动一次；一旦开始当天行动，当前位置锁定，当天不能再移动。
- 地点随机事件共60组（12地点×5组），人物通用互动模板32组，情侣专属互动模板6组。
- 主角与第一个达到“生死之交”阈值的异性角色自动成为唯一情侣；情侣有专属互动剧情。
- 角色姓名、道具名称、地点名称、生命/健康/关系等关键信息使用不同颜色高亮。
- 许棠：生命上限4；“冷静判断”每5天可重试一次非战斗检定；专属笔记本探索加成12%。
- 管理后台新增敌对自动战斗概率、事件去重窗口、互动去重窗口、情侣阈值与NPC早期保护参数。
- 普通难度近似回归模型约49%通关；NPC前30/50天死亡概率仍低于20%/50%目标。

## 本地启动

```bash
npm start
```

打开：`http://localhost:3000`

管理后台：`http://localhost:3000/admin`

默认管理密码：`818181`（部署后请立即修改）。

## Zeabur

1. 将本目录上传到 GitHub。
2. Zeabur 新建 Project → Deploy New Service → GitHub。
3. 选择仓库后直接部署；启动命令为 `npm start`。
4. 建议挂载持久化 Volume 到 `/data`，并设置环境变量：

```text
ADMIN_DATA_DIR=/data
```

这样管理后台设置与排行榜会在重新部署后继续保留。
