# 《八十一天 DAY 81》v2.4

## v2.4 主要更新

- 右上角扬声器改为**总静音**：背景音乐与所有操作音效同时静音/恢复；本局资料里的BGM曲目选择仍会被记忆。
- 小/中/大三档显示字体现在同时作用于**探索结果、行动结果、移动事件结果**；多个效果自动分行显示。
- “我的窝棚”强化材料提示：所需木材/藤条/零件以更大字号和颜色显示当前数量/需要数量；材料不足时图片中央显示“材料不足”；满足升级条件且角色正在窝棚所在地时，图片中央直接显示升级按钮。
- 新地点场景中的其他角色头像调整到画面**中间偏下**位置，兼顾识别度和上方场景文字。
- 探索与移动事件的选项/结果区域下移并缩短，把更多画面空间让给上方场景与描述。
- 营地材料出现在事件结果中时，**材料名称与数量高亮**。
- 人物列表实时得分重新缩放：每位角色开局约为 **20分**，重点体现本局生存、探索、资源、窝棚和互动成长，最高限制为 **899分**，不再开局数百分。
- 本版没有改变存档结构，继续使用 `day81_save_v23`，v2.3 进行中的本地存档可继续使用。


单人卡牌 / 荒岛生存 / 人物关系 / 轻策略网页游戏。项目无需数据库和大模型 API，可直接通过 Node.js 部署到 Zeabur。

## v2.3 主要更新

- “本局资料”新增字体大小：小 / 中 / 大三档，可随时切换。
- 新增四首原创轻柔循环背景音乐：温柔的海风、静谧森林、星空之下、晨曦之光；可关闭。手机端仍通过首次触摸解锁音频。
- 人物互动改为 RPG 式逐句播放：大头像 + 对话框，一句一句推进，全部对白结束后才出现玩家选项。
- 地点场景中的人物头像进一步放大。
- 海岛总地图重绘为 3:4 大幅面日漫风地图，加入山峰、溪流、树林、沙滩、山洞、沼泽、营地和飞机残骸等细节。
- 每天开始时六名角色随机决定行动顺序；排在主角之前的 NPC 会先行动，排在主角之后的 NPC 会在主角结束当天后行动。
- 玩家第一次拥有足够搭建一级窝棚的材料时会收到提醒。
- 探索、途中事件、互动和物资变化的结果改为描述性反馈，并明确显示角色姓名、物品数量、生命/健康及关系变化。
- 人物列表增加“当前得分”，综合生命、健康、属性、背包、探索、窝棚和本局表现计算，并按得分从高到低排序。
- DAY 20 后，拥有窝棚的角色会在人物列表显示窝棚所在地。
- NPC 会按个性在每天开始后有 25%—40% 概率返回/留在自己的窝棚；灾害发生当天有 88% 概率优先前往窝棚或公共营地。
- 情侣必须确定唯一共同住所：两人已有两座窝棚时由玩家选择其一，另一座废弃；只有一座时自动成为共同的家。
- 情侣同日在共同窝棚或林中公共营地过夜时，有 85% 概率触发亲密夜间剧情，共 5 个文学化、非露骨模板，并显示红心升腾动画。
- 亲密剧情后双方健康补满；女性第二天力量/敏捷/知识/幸运临时 +1（最高按 5 计算）；男性第二天只能休整，不能移动、探索或互动。
- 情侣之间禁止抢夺和攻击。
- 游戏失败与 DAY 81 通关分别增加独立动态结局演出和音效；演出后点击“查看表现”进入最终评分、评价和排行榜提交页。
- 普通难度的 NPC 早中期保护延长至 DAY 60：目标为 DAY30 前死亡率 <20%，DAY60 前死亡率 <40%。

## 平衡模拟

运行：

```bash
npm run simulate -- 20000
```

当前简化回归模型目标：

- 玩家六角色平均通关率保持在约 50% 上下；
- NPC DAY30 前死亡率低于 20%；
- NPC DAY60 前死亡率低于 40%。

## 本地启动

```bash
npm start
```

浏览器访问：

```text
http://localhost:3000
```

## Zeabur 部署

1. 将整个 `day81` 项目上传 GitHub。
2. 在 Zeabur 创建 Project → Deploy New Service → GitHub。
3. 选择仓库，启动命令保持 `npm start`。
4. 添加域名后即可访问。

### 推荐持久化

为了让管理后台设置、管理员密码和排行榜在重新部署后仍保留，建议挂载 Volume：

```text
/data
```

并设置环境变量：

```text
ADMIN_DATA_DIR=/data
```

管理后台：

```text
https://你的域名/admin
```

默认管理密码：

```text
818181
```

首次部署后请立即修改。
