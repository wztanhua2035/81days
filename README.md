# 八十一天 DAY 81 · v1.6

可直接部署到 Zeabur 的单人荒岛卡牌生存游戏。无需数据库或大模型 API。

## v1.6 主要更新

- 每天的 **探索** 与 **人物互动** 分开计算：各最多进行 1 次；移动不消耗这两次行动。休整会占用当天探索次数。
- 海岛地图增加溪流、山脊、小路、沙地、潮池、树林、营地、残骸、海浪和云影等细节。
- 新增“健康充盈”规则：健康已经为 3 时再次获得健康，角色生命 +1、健康变为 1；生命已满时仍按规则将健康变为 1。
- 地点随机事件从 **36 增加到 48（+33%）**；额外增加 8 组关系驱动的人物互动情节模板，并与六名角色的个人对白混合。
- 重复事件控制加强：同一地点最近 3 个事件、全局最近 18 个探索事件、最近 7 个互动情节会优先避开。
- 普通难度重新调平：近似 40,000 局/角色回归测试中，六角色平均通关率约 **51%**。NPC 的前 30 天、前 50 天死亡率均控制在目标范围内。
- 音效升级为多音节 Web Audio，默认音量提高，并继续针对 iPhone Safari、Android Chrome、微信内置浏览器进行触摸解锁。
- 文字显示优化：事件正文、选项说明、道具高亮、每日行动状态和地图标签更清楚。

## 普通难度近似平衡结果

运行：

```bash
npm run simulate -- 40000
```

当前压力模型结果约为：

- 玩家六角色平均通关率：约 51%
- NPC DAY30 前死亡率：各角色均低于 20%
- NPC DAY50 前死亡率：各角色均低于 50%

该模拟用于调参回归，真实玩家选择、营地建设、剧情链和人物关系会造成波动。

## 每日流程

```text
新的一天
→ 显示当前地点状况
→ 可移动一次
→ 可探索一次
→ 可与一名同地点角色互动一次
→ 可随时使用消耗品
→ 结束今天
→ NPC 行动
→ 大危机 / 夜间事件
→ 状态结算
→ 下一天
```

探索和互动顺序不限。例如可以先探索再聊天，也可以先互动再探索。未使用的行动次数在结束当天时作废。

## 数据持久化

推荐 Zeabur 挂载 `/data` Volume，并设置：

```text
ADMIN_DATA_DIR=/data
```

排行榜、管理密码和后台设置会保存在该目录；个人游戏进度使用浏览器 localStorage。

## 本地运行

Node.js 18+：

```bash
npm install
npm start
```

访问：

```text
http://localhost:3000
```

## Zeabur 部署

1. 将 `day81` 文件夹全部内容上传到 GitHub。
2. Zeabur 新建 Project → Deploy New Service → GitHub。
3. 选择仓库，启动命令为 `npm start`。
4. 项目自动读取 `process.env.PORT` 并监听 `0.0.0.0`。
5. 添加域名即可运行。
6. 推荐配置 `/data` Volume 与 `ADMIN_DATA_DIR=/data`。
