# 《八十一天 DAY 81》v1.8

单人卡牌 / 荒岛生存 / 人物关系 / 连续剧情 / 营地建设网页游戏，可直接部署到 Zeabur。

## v1.8 核心变化

- 12个海岛地点全部加入独立场景图片，当前地点名称下方直接显示场景。
- 同地点其他幸存者的头像与姓名叠加显示在场景图上，点击头像可查看人物信息、状态与关系。
- 每个新的一天先显示当前场景状况，再由玩家选择“留在当地”或“前往其他地点”；作出选择后当天地点锁定。
- 到达新地点后，场景描述会写出同地点人物正在进行的活动。
- 主角同一天可以与当前地点的每一名其他幸存者分别互动一次；已互动人物会单独标记。
- 人物互动通用剧情模板增加到60组，另外保留6组情侣专属互动。敌对、冷淡、普通、信任、生死之交关系会影响可出现剧情、选择和关系结果。
- 删除“继续今天”按钮。探索或人物互动结束后，尚未完成的可用行动直接显示在“结束今天”之前。
- 人物互动近期去重窗口默认提高到18，减少连续出现相似剧情。
- 同时包含8格背包、永久专属初始道具、60组地点事件、情侣关系、连续剧情、营地建设、大危机、三档难度、音效、排行榜和管理后台。

## 本地启动

```bash
npm start
```

打开：`http://localhost:3000`

管理后台：`http://localhost:3000/admin`

默认管理密码：`818181`（部署后请立即修改）。

## Zeabur

1. 将本目录完整上传到 GitHub。
2. Zeabur 新建 Project → Deploy New Service → GitHub。
3. 选择仓库后直接部署；启动命令为 `npm start`。
4. 建议挂载持久化 Volume 到 `/data`，并设置环境变量：

```text
ADMIN_DATA_DIR=/data
```

这样管理后台设置与排行榜会在重新部署后继续保留。

## 存档说明

v1.8 使用新的浏览器存档键 `day81_save_v8`。由于每日行动流程发生变化，建议玩家部署后重新开始一局，不继续旧版进行中的存档。
