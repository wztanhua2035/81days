# 《八十一天 DAY 81》v2.2

单人卡牌 / 荒岛生存 / 人物关系 / 智能 NPC / 公共营地 / 个人窝棚网页游戏，可直接部署到 Zeabur。

## v2.2 核心变化

- 修正生命溢出：角色**生命已经满值**时再次获得生命恢复，生命保持不变，并把健康补到3；如果生命与健康都已满则不浪费状态。
- 场景叙事进一步视觉化：每天的地点状况直接叠加在日漫场景图上；探索事件标题与正文的一部分叠加在地点图片上；人物互动前两轮对话叠加在互动场景图上，后续对话在下方继续显示。
- 场景描述、探索描述、互动对白字号整体提高，同时继续保持手机单屏布局与局部滚动，不让整页反复上下滚动。
- 道具体系重新平衡并大幅扩容：**74种道具，其中42种可消耗道具**。新增更多食物、饮水、医疗、防护与求救物资；高价值恢复物资使用较低掉落权重，避免物资扩容破坏难度。
- 前往其他地点时新增途中事件：每次真正移动有**30%概率**触发特别事件，包含捡到物资、突然阵雨、湿石打滑、马蜂惊扰、临时过水等。多数直接发生，少数提供三选一决策。
- 移动途中另有**35%概率**遇见其他幸存者并触发人物互动剧情。途中相遇同样计入该角色当天的一次互动机会。
- 地点探索事件从60组提高到**78组（+30%）**。
- 通用人物互动模板从60组提高到**92组（约+53%）**。
- 所有人物互动的通用对话结构由4轮扩展为约6轮，并加入职业、人物性格和关系状态对应的更深入回应；关系会继续影响剧情模板、选项和效果。
- 人物互动近期去重窗口默认提高到24，并在候选模板中随机抽取，降低大事件池中少数模板反复出现的概率。
- 保留人物动漫头像、12个日漫地点场景、情侣剧情、连续剧情链、大危机、公共营地、个人窝棚、NPC AI、夜间互动、排行榜、管理后台和手机音频解锁。

## 当前内容规模

- 6名可选主角 / NPC
- 12个海岛地点
- 78组地点专属探索事件
- 92组通用人物互动模板
- 6组情侣专属互动
- 16组移动途中随机事件
- 74种道具，其中42种可消耗
- 8格背包，相同消耗品每格最多叠加2个
- 公共营地 + 三级个人窝棚 + 最多4件窝棚设施

## 游戏核心流程

1. DAY 1 从飞机迫降后的昏迷中醒来。
2. 每天清晨查看当前地点、天气、人物和危机提示。
3. 决定留在当地或前往其他地点；移动途中可能触发随机事件或人物相遇。
4. 当天可以探索一次，并分别与当前地点每名其他角色互动一次。
5. 使用和管理物资、关系、公共营地、个人窝棚与设施。
6. 夜晚结算 NPC 行动、夜间事件、夜间人物互动、结构损坏、健康与生命。
7. 活到 DAY 81 获救并进入评分和排行榜。

## 本地启动

需要 Node.js 18 或以上版本：

```bash
npm start
```

游戏：`http://localhost:3000`

管理后台：`http://localhost:3000/admin`

默认管理密码：`818181`，部署后请立即修改。

## Zeabur 部署

1. 将本目录完整上传到 GitHub。
2. 在 Zeabur 新建 Project → Deploy New Service → GitHub。
3. 选择仓库并部署，启动命令为 `npm start`。
4. 不需要数据库，也不需要任何大模型 API。
5. 建议挂载持久化 Volume，例如 `/data`，并设置：

```text
ADMIN_DATA_DIR=/data
```

这样管理后台设置和排行榜在重新部署后仍会保留。
